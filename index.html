INSTRUCCIONS

Ajuda

Funcionament de SSPC2026.

01

Carrega les preguntes

Importa el fitxer CSV o afegeix preguntes a l’editor.

02

Tria el teu temari

Selecciona tot el temari o una lliçó concreta. Tria entre 10, 30 o 50 preguntes (sense repeticions).

03

Respon i revisa

Un alumne marca les respostes a l’ordinador mentre la resta anota les seves. Al final apareix una graella de solucions numerades per autocorregir-se. Des de casa cada alumne pot practicar individualment.

04

Guarda el banc a GitHub

Exporta el banc en CSV i substitueix preguntes.csv al teu repositori. Es carregarà automàticament a PC i mòbil.

Format de les dades

El programa carrega automàticament preguntes.csv des de GitHub Pages. No cal convertir-lo a JSON.

La primera fila ha de ser aquesta capçalera, en aquest ordre:

id,tema,enunciat,opcio_a,opcio_b,opcio_c,opcio_d,correcta,explicacio

Una pregunta ocupa una fila. El camp tema identifica la lliçó (per exemple 1.2); el camp bloc ja no existeix. correcta és una lletra A/B/C/D. La columna explicacio és opcional. CSV en UTF-8; les comes, les cometes i els salts de línia es tracten correctament. Els CSV antics que tinguin bloc es poden importar: aquesta columna s’ignora i s’elimina en exportar.

Actualitzar preguntes a GitHub

Edita preguntes.csv amb LibreOffice o Excel, desa'l en CSV UTF-8 i substitueix-lo a GitHub. No cal tocar index.html ni app.js. Si tens canvis locals, exporta'ls abans de prémer «Restaurar CSV de GitHub».

Dades i privacitat

Les respostes i els resultats es desen al navegador de cada dispositiu. GitHub Pages no pot escriure automàticament al repositori: si edites preguntes dins del programa, prem Exportar CSV i penja'l a GitHub manualment. Els resultats de PC i mòbil no se sincronitzen.

Correcció

Una resposta correcta suma un encert; una incorrecta, un error; les no contestades es compten a part. El percentatge és encerts / preguntes totals × 100, sense penalització addicional.
